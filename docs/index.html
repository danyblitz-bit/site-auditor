SiteAuditor

Audit any website in one command: SEO, performance, and broken links — with CI-friendly exit codes and CSV/JSON export.

Python CLI CI-friendly Open Source MIT License
View on GitHub Get the DevTools Bundle

SEO Audit

Checks title, meta description, H1, Open Graph, viewport, canonical, and image alt text in one pass.

Performance Check

Measures response time, page size, gzip, caching headers, HSTS, and CSP. No web app, no waiting queue.

Broken Link Detection

Crawls internal links and flags 404s and timeouts so you can fix them before your users find them.

CI-Friendly Exit Codes

Exits 0 when the score is ≥ 70, 1 when the site needs work. Drop it straight into a pipeline.

CSV & JSON Export

Feed audit results into your own dashboards, reports, and tooling with two flags.

Local & Private

Runs on your machine. No account, no cloud, no submission of your site to a third party.

Quick Start

  1. pip install -r requirements.txt
  2. Run an audit: python -m tools.site-auditor https://example.com
  3. Export results: python -m tools.site-auditor https://example.com --json report.json --csv report.csv
  4. Read the score: 0 means ship it, 1 means fix it.
